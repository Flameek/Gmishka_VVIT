## Структура лабораторных работ

### **Лабораторная работа №1: Работа со структурами данных, циклами и условными операторами**
**Цель:** Освоить фундаментальные конструкции языка Python, необходимые для реализации алгоритмов ИИ.

**Что создавал/изучал:**
- **Структуры данных**: Списки Python, индексация, модификация элементов
- **Циклы**: Реализация циклов `for` и `while` для итеративной обработки данных
- **Условные операторы**: Логические конструкции `if-elif-else` для принятия решений
- **Практические задания**: Программы для обработки числовых последовательностей и сравнения значений

**Связь с ИИ:** Базовые алгоритмы обработки данных, необходимые для предобработки данных в машинном обучении.

### **Лабораторная работа №2: Функции в Python и базовые алгоритмы**
**Цель:** Освоить принципы модульного программирования и реализации алгоритмических конструкций.

**Что создавал/изучал:**
- **Функции**: Создание и использование пользовательских функций
- **Аргументы функций**: Позиционные, именованные и аргументы по умолчанию
- **Алгоритмические задачи**: Реализация проверки простых чисел, поиска максимумов
- **Модульность**: Разделение кода на логические блоки

**Связь с ИИ:** Функциональный подход к созданию модулей нейронных сетей и алгоритмов оптимизации.

### **Лабораторная работа №3: Работа с файлами в Python**
**Цель:** Освоить операции ввода-вывода данных и обработку исключений.

**Что создавал/изучал:**
- **Файловые операции**: Открытие, чтение, запись файлов
- **Методы чтения**: Полное чтение, построчная обработка
- **Обработка исключений**: Механизмы `try-except` для устойчивости программ
- **Работа с текстовыми данными**: Сохранение и загрузка данных

**Связь с ИИ:** Работа с датасетами, логированием результатов обучения моделей, загрузка конфигураций.

- **Пакеты**: Организация структуры проекта

**Связь с ИИ:** Структурирование проектов машинного обучения, использование библиотек (NumPy, Pandas, TensorFlow).
